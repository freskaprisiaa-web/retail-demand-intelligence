# Reporting Cadence

| Cadence | Core content | Decision |
|---|---|---|
| Weekly | Forecast exceptions, bias, high-volatility segments, data freshness | Immediate replenishment/data actions |
| Monthly | Sales, transactions, units/transaction, MoM, promotion penetration, forecast accuracy | Store/family action plan |
| Quarterly | YoY mix shifts, recurring exceptions, improvement backlog progress | Process or model prioritization |
| Annual | Like-for-like trend, model performance history, completed improvements | Roadmap and measurement design |

Every readout must state the reporting window, last refresh date, data limitations, KPI definitions, and action owner.
